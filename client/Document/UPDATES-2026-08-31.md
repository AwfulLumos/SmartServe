# Smartserve  - System Updates & Email Authentication Documentation
**Date:** August 31, 2026  
**Module:** Authentication, Email Delivery System & Password Reset Workflow  

---

## 📑 Overview
This document details the architectural refactoring, mailer configuration, and password reset workflow updates implemented for **SmartServe 2.0**.

---

## 1. 📧 Email Delivery & SMTP Configuration (`server/config/mailer.js`)
- **Gmail Service Integration**: Configured `nodemailer` to utilize native Gmail service (`service: 'gmail'`) with OAuth/App Passwords.
- **IPv4 Resolution Enforcement**: Added `dns.setDefaultResultOrder('ipv4first')` to bypass Windows socket resolution issues (`ECONNREFUSED ::1:587`).
- **Production Terminal Logging**: Removed dev-mode terminal code printing. Replaced with structured email confirmation logs:
  ```text
  Processing password reset request for Staff/Student User: user@example.com
  ==================================================
  RESET CODE EMAIL SENT SUCCESSFULLY
  Sent To: user@example.com
  Message ID: <xxxx-xxxx-xxxx@gmail.com>
  ==================================================
  ```

---

## 2. Universal Password Reset Controller (`server/controllers/passwordController.js`)
- **Universal User Search**: The main `/forgot-password` endpoint searches both the **Staff/Admin** (`User`) collection and the **Student/Employee** (`Student`) collection.
- **OTP Generation & Security**:
  - Generates a cryptographically random 6-digit OTP code using `crypto.randomInt(900000)`.
  - Sets code expiry to **15 minutes** (`Date.now() + 15 * 60 * 1000`).
  - Saves `resetCode` and `resetCodeExpiry` temporarily on the matched account in MongoDB.
  - Automatically wipes `resetCode` and `resetCodeExpiry` to `null` once the password reset completes.
- **Flexible Field Validation**: Accepts either `password` or `newPassword` in POST request payloads to ensure full compatibility with frontend forms.

---

## 3. Student Authentication Portal (`server/controllers/studentAuthController.js`)
- **Student Password Reset**: Allows students to request password resets by typing either their **School ID** or their registered **Email address**.
- **Student Login Authentication**:
  - Requires **School ID** (`schoolId`) and **Password** for student login at `/student/login`.
  - Protects student accounts against invalid credentials or account lockouts.

---

## 4. Frontend Portal Navigation & UI Enhancements
- **Dual Portal Redirection (`ResetPassword.jsx`)**:
  Upon successful password reset, the screen presents two explicit navigation options:
  - **Sign In to Student Portal** (`/student/login`)
  - **Sign In to Staff / Admin Portal** (`/login`)
- **Responsive Error Handling**:
  Displays human-readable error banners (e.g. `"No account found with that email address"`) if an input does not match any record.

# SmartServe Updates

**Date:** August 22, 2026

## Overview

This update introduces significant improvements to the administrator portal user experience, user management workflows, account security, and inventory analytics. Key updates include custom animated portal transitions, consolidated student lookup with a detailed tabbed modal, a complete soft-delete and restoration system for user accounts, in-app password changes for administrators, enhanced restock data export controls, humanized forecasting documentation, and responsive usability fixes across the application.

---

## Admin Portal Transitions & User Experience

- **Post-Login Portal Loader**:
  - Implemented a sleek, 3-second animated loading transition (`AdminLoadingScreen`) displayed immediately after successful admin login.
  - Ensures a polished, high-end visual entrance before revealing the dashboard.
- **Interactive Animated Logout Screen**:
  - Integrated a dedicated 3-second animated logout screen (`AdminLogoutScreen`) featuring custom farewell messaging and smooth visual fade-out transitions.
  - Fully executes session cleanup and context resets upon completion of the farewell animation.
- **Smooth Page Navigation Fade-in Transition**:
  - Added a hardware-accelerated CSS keyframe transition (`adminPageFadeIn`) in `index.css` paired with route-keyed re-mounting (`key={location.pathname}`) in `AdminLayout.jsx`.
  - When switching between any admin views (Dashboard, Orders, Menu, Inventory, Analytics, User Management, Rewards, Settings), page content smoothly fades in with an upward slide animation (0.35s ease-out).

## Consolidated Student Lookup & Tabbed Detail View

- **Tabbed Student Inspector Modal**:
  - Upgraded the student management table in `RegisterStudent.jsx` with an interactive 4-tab modal for deep student lookup:
    - **Overview Tab**: Displays student profile details, RFID tag number, point balances, account status, and registration date.
    - **Orders Tab**: Displays real-time order history, purchased items, and total spending log.
    - **BYOC Tab**: Displays Bring Your Own Container participation, container check-ins, and eco-discount log.
    - **Redemptions Tab**: Displays reward point redemption logs and redeemed perks.
- **Clickable Row Navigation**:
  - Made table rows directly clickable to allow quick inspection of student account profiles.
- **Sidebar Menu Streamlining**:
  - Consolidated student management workflows into "Register User" and removed redundant separate "User Lookup" links from the `AdminLayout` sidebar navigation.

## Soft Delete & Account Restoration System

- **Active vs. Soft-Deleted Account Views**:
  - Added filter tabs on the user management interface allowing administrators to toggle between viewing active students and soft-deleted accounts.
- **Restore and Delete Backend Integration**:
  - Implemented full API integration for soft-deleting (`DELETE /api/students/:id`) and restoring (`PUT /api/students/:id/restore`) student accounts without data loss.
- **Dropdown Menu Positioning Fix**:
  - Resolved UI clipping issues by implementing dynamic menu positioning for action dropdowns near the bottom of the user table.

## Analytics, Restock Table & Humanized Guidance

## Order Management Batch Operations & Custom Dropdown Styling

- **Stage-Based Batch Action Buttons**:
  - Added quick batch action buttons to `Orders.jsx`:
    - **Prepare All Pending**: Transitions all pending orders to "Preparing" in one click.
    - **Mark All Ready**: Marks all preparing orders as "Ready" for pickup.
    - **Complete All Ready**: Marks all ready orders as "Completed".
    - **Complete All Active**: Completes all pending, preparing, and ready orders simultaneously.
- **Multi-Select Checkbox System**:
  - Added header and row checkboxes allowing administrators to select multiple student orders.
  - Added a floating selection toolbar for batch actions on selected orders (Prepare, Mark Ready, Complete, Cancel).
- **Expanded Filtering & Sorting**:
  - Added Date Range filter (All Dates, Today, Yesterday, Last 7 Days) and Sort controls (Newest, Oldest, Price High/Low).
- **Bulk Status Update Endpoint**:
  - Created `PATCH /api/orders/bulk-status` backend API endpoint supporting batch updates with audit logging and student push notifications.
- **Order Details Modal Viewport Positioning Fix**:
  - Resolved an issue where opening the Order Details modal while scrolled down the table required scrolling up to view the modal overlay.
  - Adjusted CSS animation keyframe properties in `index.css` to prevent parent containing block traps and updated modal overlay styling in `Orders.jsx` (`z-[9999] backdrop-blur-sm my-auto`) to guarantee the modal remains centered in the active screen viewport regardless of scroll position.

## Student Login & Logout Loading Screens

- **Animated Post-Login Loading Screen** (`StudentLoginLoadingScreen`):
  - Added a full-screen 3-second animated loading overlay that appears immediately after a student successfully signs in.
  - Displays the SmartServe logo inside a glassmorphism circle, "Student Portal" label, a dynamic pulsing status text (Connecting → Loading your profile & menu → Almost ready…), and a smooth green gradient progress bar with percentage and remaining seconds.
  - Includes a **"Skip loading ›"** button for quick-access users.
  - Triggered via a `sessionStorage` flag (`smartserve_student_just_logged_in`) set in `StudentLogin.jsx` and detected on mount in `StudentDashboard.jsx` — mirrors the existing admin portal login loading pattern.

- **Animated Logout Farewell Screen** (`StudentLogoutScreen`):
  - Added a 3-second animated logout overlay that plays when the student taps the **Logout** button from the Settings panel.
  - Features the student's avatar (profile photo or name initials) centered inside a **draining red SVG countdown ring**, a "Logging out in Xs" badge, a personalized goodbye message with the student's full name, and a red→amber progress bar.
  - After the 3-second animation completes, the session is cleared and the user is redirected to `/student/login`.
  - The logout button in `ProfileView` now triggers `handleLogout` (passed as `onLogout` prop from `StudentDashboard`) instead of calling the bare `logout()` function directly, keeping animation state fully centralized in `StudentDashboard`.


## Student Feedbacks System

- **MongoDB Database Model (`server/models/Feedback.js`)**:
  - Created a dedicated `Feedback` collection with attributes: `student`, `studentName`, `studentSchoolId`, `category` (*General*, *Food Quality*, *Canteen Service*, *App Issue*, *Suggestion*), `rating` (1–5 stars), `message`, `status` (*pending*, *reviewed*, *resolved*), `adminResponse`, `respondedAt`, and `respondedBy`.
- **Backend API Controllers & Routes (`server/controllers/feedbackController.js`, `server/routes/feedbackRoutes.js`)**:
  - `POST /api/feedback/student`: Allows authenticated students to submit ratings, categories, and messages.
  - `GET /api/feedback`: Enables admins to fetch all student feedback with keyword search, category filters, rating filters, status filters, and real-time aggregated metrics (*Total Feedbacks*, *Average Rating*, *Pending*, *Resolved*).
  - `PATCH /api/feedback/:id/status`: Allows admins to toggle status (*Pending*, *Reviewed*, *Resolved*) and post/edit admin replies.
  - `DELETE /api/feedback/:id`: Allows admins to remove inappropriate or duplicate entries.
- **Admin Portal Feedbacks Page (`client/src/pages/admin/Feedbacks.jsx`)**:
  - Built a dedicated admin view with summary KPI cards, star rating displays, student info badges, quote boxes, filter toolbars, and an admin response modal.
  - **Student Profile Picture & Live Name Sync**: Replaced static single-letter avatars with the student's actual uploaded profile picture (`profileImage`). Dynamically resolves student name (`student.fullName`) and school ID (`student.schoolId`) from the populated user record, ensuring profile edits (e.g. name changes or corrections) reflect live in real-time on the Feedbacks portal with updated 2-letter initials fallback.
  - **Custom Dropdown UI**: Replaced native browser select inputs with a custom styled dropdown component featuring smooth hover highlights, green selection indicators (`#4a6741`), animated popovers, and outside-click auto-dismissal.
- **Admin Sidebar Integration (`AdminLayout.jsx`)**:
  - Added a new **"Feedbacks"** link with a chat bubble icon (`IoChatbubblesOutline`) directly in the admin navigation panel.
- **Live Student Portal Feedback History & Admin Reply View (`StudentDashboard.jsx`)**:
  - Added a **"My Submitted Feedbacks"** card inside the **Support & Help** settings view where students can see all past feedbacks they have submitted with categories, star ratings, submission timestamps, live status badges (*Pending*, *Reviewed*, *Resolved*), and a **Delete Feedback** button (`IoTrashOutline`).
  - Features a dedicated **Admin Response Box** displaying the admin's reply message, responder name, and response timestamp whenever canteen management replies to their feedback.
  - **Instant Notifications**: Sends socket & push notifications (`Feedback Response Received`) directly to the student's notification bell when an admin posts a reply.
  - **Student Self-Delete Endpoint**: Added `DELETE /api/feedback/student/:id` backend route allowing students to securely delete their own feedback entries.
- **Global Dropdown Styling (`client/src/styles/index.css`)**:
  - Added global custom SVG chevron styling and green active option highlights (`#e8f5e2`) for standard `<select>` controls.

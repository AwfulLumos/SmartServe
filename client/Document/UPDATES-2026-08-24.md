## Student Portal DOM Nesting Fix & Emoji Removal

### Objective
Fix React DOM nesting validation warnings on the Student Orders page and clean up re-order UI components by replacing emojis with vector icons and clean toast notifications.

### Summary of Changes

1. **Fixed React DOM Nesting Warning (`validateDOMNesting`)**
   - **Root Cause:** In `StudentDashboard.jsx` (`OrdersView`), each past order card was rendered as an outer `<button>` containing an inner `<button>` for the "Re-Order" action, causing a `<button> cannot appear as a descendant of <button>` DOM nesting warning.
   - **Fix:** Converted the outer card element to a `<div>` with `role="button"`, `tabIndex={0}`, keyboard navigation handlers (`onKeyDown`), and `cursor-pointer` styling.

2. **Cleaned Up Re-Order Emojis & Icons**
   - Removed emoji characters (`⚡` and `⭐`) from `handleReOrder` and `handleSetUsual` toast notifications in `StudentDashboard.jsx`.
   - Replaced yellow sparkles icons (`IoSparklesOutline`) with sleek `IoBookmarkOutline` vector icons in `PastOrderDetail` modal and `MyUsualCard`.

## Audit Log Unlimited CSV Export & Database Maintenance Deletion

### Objective
Allow administrators to export **all** audit log history without pagination caps and provide individual & bulk log deletion tools to maintain database performance and prevent system slowness.

### Summary of Changes
1. **Unlimited CSV Export (`all=true`)**
   - Updated backend controller (`auditLogController.js`) and API route to support `all=true` query parameter, bypassing pagination limits.
   - Frontend `handleExportCSV` now requests all matching logs without truncating at 100 entries.

2. **Single Log Entry Deletion**
   - Added `DELETE /api/audit-logs/:id` backend route restricted to administrators.
   - Added an **Action** column with a red trash icon (`IoTrashOutline`) per row in `AuditLogTab` with a confirmation modal before deletion.

3. **Bulk Log Clear & Storage Maintenance**
   - Added `DELETE /api/audit-logs/clear-all` backend route supporting filter-based bulk log purging.
   - Added a **`Clear Logs`** button (`IoTrashOutline`) next to `Export CSV` with warning modal to allow admins to clear log history safely.

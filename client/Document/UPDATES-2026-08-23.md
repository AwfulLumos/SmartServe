# SmartServe - Project Updates (2026-08-23)

## Summary of Changes & Enhancements

This document details all feature additions, UI enhancements, real-time data synchronization fixes, and API updates completed on **August 23, 2026**.

* **Download Button Integration**: Added a dedicated **"Download QR Code"** button (`IoDownloadOutline`) inside the `MyQRView` card in the Student Portal.

### Student Portal Theme Architecture & Tailwind Dark Mode Fix (`tailwind.config.js` & `StudentDashboard.jsx`)
* **Explicit Class-Based Dark Mode (`tailwind.config.js`)**:
  - Configured `darkMode: "class"` in Tailwind configuration so all `dark:` utility variants are strictly governed by the `.dark` class on `document.documentElement` rather than OS system preference (`prefers-color-scheme`).
  - Ensures the application opens in **Light Mode by default** for all users, activating dark theme styles only when explicitly toggled on in Settings.
* **Reactive Theme State Synchronization (`StudentDashboard.jsx`)**:
  - Added a reactive `useEffect` hook bound to the `darkMode` state that manages class list toggling on `document.documentElement` and synchronizes user preference in `localStorage` (`smartserve_theme`).
  - Prevents theme persistence issues when switching back to Light Mode, guaranteeing zero residual dark styling across all components.

### API Endpoint Summary

| Method | Endpoint | Access | Purpose |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/feedback/student` | Student | Submit new feedback with category & 1-5 star rating |
| `GET` | `/api/feedback/student/my` | Student | Fetch logged-in student's feedback history & admin replies |
| `DELETE` | `/api/feedback/student/:id` | Student | Delete logged-in student's own feedback entry |
| `GET` | `/api/feedback` | Admin / Staff | Retrieve all student feedbacks with search, category, status & rating filters |
| `PATCH` | `/api/feedback/:id/status` | Admin / Staff | Update feedback status (*Pending*, *Reviewed*, *Resolved*) and post admin replies |
| `DELETE` | `/api/feedback/:id` | Admin / Staff | Remove feedback entries permanently |
| `GET` | `/api/forecast/restock` | Admin / Staff | Retrieve demand forecasting & enriched COGS profit metrics |
| `GET` | `/api/forecast/income` | Admin / Staff | Retrieve income prediction series based on order history |
| `PUT` | `/api/inventory/:id` | Admin / Staff | Update inventory item details including `unitCost` |
